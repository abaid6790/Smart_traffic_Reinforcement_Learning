# Privacy policy

Last updated: 2026-10-11 · Applies to version 1.0.0

This policy describes what this program does with information. It is written for a locally run educational program and
is **not legal advice**.

## The short version

* The program runs **entirely on your computer** and works offline.
* It **collects no personal data**, has no accounts, no analytics, no telemetry and no advertising, and it **sends nothing
  anywhere**.
* It writes some files on your computer (listed below). They stay there until you delete them.
* The log file can contain **file paths**, which may include your computer's user name. Check it before you share it.

## Who is responsible

The project author, _your name_ (_your contact_). Because nothing leaves your computer, the author receives no data from
your use of the program.

## What the program stores, and where

All locations are inside the project folder unless you choose another one.

| File | What it contains | Personal data? |
|---|---|---|
| `config/user_settings.json` | Your settings (traffic, light, learning, display values) | No |
| `models/q_learning_model.json` | The trained table of numbers and training information (episodes, scenarios, seed, parameters, time saved) | No |
| `results/csv/training_*.csv` | One row of numbers per training episode | No |
| `results/graphs/*.png` | Training graphs | No |
| `results/experiment_*/` | Experiment reports: numbers, settings used, graphs | No |
| `logs/application.log` | Technical events and errors with time stamps (see below) | **Possibly**: file paths |
| Screenshots you request (`--screenshot`) | A picture of the program's own window | No |

### The log file

`logs/application.log` records when the program started, which screen was opened, settings values, file paths it read or
wrote (for example the model and settings files), results of runs, and error details with technical tracebacks. It does not
record keystrokes, screen contents, the contents of your other files, or anything about other programs.

File paths on Windows usually look like `C:\Users\<your user name>\...`, so the log can reveal your user name and folder
names. The log is limited to about 1 MB per file with 3 older copies kept (about 4 MB in total) and is never uploaded. Delete
the `logs` folder at any time; it is recreated when needed. If you share the log, for example with a supervisor or in a
bug report, read it first and remove anything you do not want to share.

## What the program does not do

* No network connections (the code imports no networking library).
* No cookies or browser storage (see [COOKIE_POLICY.md](COOKIE_POLICY.md)).
* No tracking, profiling, advertising, or sale or sharing of data.
* No access to your camera, microphone, location, contacts or other files. It reads only its own settings, model and
  result files, and any model or settings file you point it to with `--model` or `--config`.

## Simulated data

The vehicles, roads and traffic are generated by the program from a random seed. They represent no real people, vehicles or
places.

## Your control

* **See** what is stored: open the files above; they are plain JSON, CSV, PNG and text.
* **Delete** it: use the Delete buttons in the application (model, experiments, graphs), or delete the files and folders
  yourself, including `logs`.
* **Stop** everything: close the program. Nothing runs in the background after it closes.

## Children

The program collects no data from anyone, so it collects none from children.

## If you extend the project

If you add features that handle real or personal data (for example camera images, number plates or location traces), the
simulation-only assumptions of this policy no longer hold, and you need a new privacy assessment and policy for that data.
