# Third-party notices

The project's own code is under the [MIT licence](LICENSE). It uses the libraries below. **They are not included in the
project folder**: `pip install -r requirements.txt` downloads them from the Python Package Index, and each stays under its
own licence.

| Library | Used for | Licence (from the installed package's metadata) |
|---|---|---|
| [pygame](https://www.pygame.org) | the window and drawing | GNU Lesser General Public License (LGPL) |
| [matplotlib](https://matplotlib.org) | PNG graphs (optional) | matplotlib licence (based on the Python Software Foundation licence) |
| [NumPy](https://numpy.org) | installed by matplotlib; not imported by the project's own code | BSD-3-Clause and other permissive licences |

`matplotlib` also installs further packages (for example Pillow, contourpy, cycler, fonttools, kiwisolver, packaging,
pyparsing and python-dateutil). Their licences are in their own packages. To list all installed licences run, for example:

```powershell
pip install pip-licenses
pip-licenses
```

## Notes

* **LGPL (pygame):** the project does not modify or redistribute pygame; it only imports it. If you redistribute a bundle
  that includes pygame, follow the LGPL for that bundle.
* **Fonts and images:** the project ships no third-party fonts or images. The pictures in `docs/images` are screenshots and
  graphs produced by the program itself. The window uses the fonts that pygame provides.
* **Data:** all traffic is generated by the program; no external data set is used.
* **Ideas and references:** Q-Learning is described in Watkins and Dayan (1992) and Sutton and Barto (2018); see the
  references in [docs/PROJECT_REPORT.md](docs/PROJECT_REPORT.md).

Licence texts and exact versions can change; check the packages you install.
