# Cookie policy

Last updated: 2026-10-11 · Applies to version 1.0.0

**This program does not use cookies.**

It is a desktop and command-line program, not a website or a web application. It does not run inside a browser, so there
are no cookies, no local storage, no session storage, no tracking pixels, no fingerprinting, no analytics scripts and no
third-party content. It makes no network connections at all (see [PRIVACY.md](PRIVACY.md)).

## What it stores instead

The program stores its own files on your computer (settings, a trained model, result files and a log). These are ordinary
files that you can open, copy and delete. They are not cookies and are not read by any website. The full list is in
[PRIVACY.md](PRIVACY.md).

## No consent banner needed

Because no cookies or similar technologies are used, there is nothing to consent to and the program shows no cookie
banner.

## If the documentation is published on a website

The Markdown files in this project can be opened without any website. If you publish them on a site (for example a project
page or a repository host), **that site's own cookie policy applies** to your visit there, not this one. This project does
not control it. If you build a website for the project and it sets cookies or uses analytics, you must add a banner and
update this policy before publishing it.
